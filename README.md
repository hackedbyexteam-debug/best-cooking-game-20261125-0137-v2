**Ember Kitchen** — a cozy bistro rush. Orders roll in on the board; grill the patties on the iron grill (flames, sizzle, steam), chop tomato and lettuce on the board, build each plate to match its ticket, and serve it at the pass before the customer walks out. Combo tips, a 150-second shift, three strikes and the night is over.

Every picture is drawn in code — a sunset window, copper pots, a wooden counter, burgers and pasta bowls built from vector shapes — no photos, no emoji tiles. Click to play, or use keys 1–6 for ingredients, G for the grill, T to trash a plate, Space to serve.

## Play it

```sh
node serve.ts
# open http://localhost:8080
```

## Hand it in

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
